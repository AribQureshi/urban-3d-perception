How it works

  1. Detect

    YOLOv8 finds cars, buses, trucks, bikes and people in each frame.

  2. Track

    ByteTrack links detections across frames so each object keeps one ID.

  3. Measure depth

    Depth Anything V2, a Vision Transformer, predicts metric depth for every pixel.

  4. Lift to 3D

    A pinhole camera model turns each box and its median depth into metres.

  5. Smooth

    A Kalman filter per track, trusting far objects less, gives stable distance and speed.

  6. Score

    Time to collision sets the risk level; an Isolation Forest flags unusual behaviour.
